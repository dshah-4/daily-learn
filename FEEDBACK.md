# Feedback for Daily Learn

Write notes here about what you want more or less of. `/generate-week` reads this file before every batch and follows it.

- One note per line, e.g. `more history`, `less chess`, `cards too long`, `harder quiz questions`, `more 90s hip-hop`.
- Notes stay in effect until you delete them. Optionally add a date, e.g. `2026-11-05: more science`.
- Feedback overrides the default mix, frequency, length and tone in `CONTENT_GUIDE.md`. It can't override accuracy or the file format.
